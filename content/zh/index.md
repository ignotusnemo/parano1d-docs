# ParanO(1)d

**A proof-native L1 statechain secured by proof of work.**

传统区块链存在一个根本性的架构缺陷：为了验证现在，节点必须重放过去。新全节点要从创世区块开始下载整条链并重新执行每一笔交易，因为当前状态本身无法证明其有效性。这不是暂时的工程限制，而是传统模型固有的代价。

ParanO(1)d 消除了这种依赖。

有效性只在信息完整的地方证明一次。钱包使用私有 witness 证明其支配资金的权利；矿工证明公开的交易逻辑以及精确的状态转换；网络只需验证这些证明，不再重复执行同一批计算。

每个被接受的区块都携带递归 `HistoryStep`，把区块、新 UTXO 根和此前状态链的有效性绑定在一起。新节点可以认证当前状态并验证近期可重组后缀，而不必从创世区块重新执行整条链。

当当前状态能够自证有效时，已花费状态便可删除，其占用空间也可以复用。所有权不再需要公钥或数字签名；状态增长可以直接定价；工作量证明只负责排序已经证明有效的状态转换。网络的年龄不再自动变成更高的硬件门槛。

## 根本变化

| | 传统区块链 | ParanO(1)d |
|---|---|---|
| 验证 | 每个全节点都重新执行 | witness 持有者生成证明，网络负责验证 |
| 初始同步 | 从创世区块重建状态 | 认证当前状态并验证近期后缀 |
| 所有权 | 公钥签名 | 对 Poseidon2b 原像知识的新鲜 ZK 证明 |
| 状态 | 由累积历史推导 | 精确的活 UTXO 状态本身就是共识对象 |
| 已花费输出 | 仍属于必需历史 | 槽位清空后可安全复用 |
| 工作量证明 | 排序执行日志 | 排序已证明有效的状态转换 |
| 后量子迁移 | 替换所有权方案 | 交易共识中没有需要替换的椭圆曲线方案 |

## 一次转换，只证明一次

发送 NOID 时，钱包选择自己的 UTXO，并构造一笔原子的 `PagedSpend`。它针对 `{logical_txid, input_owner}` 生成全新随机化、隐藏 witness 的授权证明。256 位支出秘密始终留在钱包内。

该授权与状态无关：其中不含 UTXO Merkle 路径，也不绑定某一个状态根。矿工持有公开的状态 witness，并单独证明每个输入确实存在、每个输出槽为空、数值与手续费守恒，以及转换后的状态根完全正确。

内存池在转发前验证完整的交易意图。矿工把已接受的意图、精确状态转换和前一个终端合并进下一步 `HistoryStep`。它先证明与 nonce 无关的区块语义，完成后才开始搜索 PoW nonce。

对等节点收到一个原子包 `{block, HistoryStep terminal}`。节点验证证明与 nonce，随后把已经证明的槽位写入应用到本地 UTXO 集。它们只物化结果，不重新执行交易逻辑。

## 挖矿依赖状态

**只有算力无法生成区块。挖矿依赖状态，并受证明门控。**

独立矿工跟随规范链，持有活 UTXO 状态，选择交易，并证明精确的下一步 `HistoryStep`。只有证明完成后，内置或外部 worker 才能搜索不可变 Poseidon2b 区块头的 nonce。孤立的哈希引擎既不能创建区块，也不能篡改其正在计算的状态转换。

因此，挖矿设施同时也是网络设施：独立区块生产者是由算力支撑、能够生成证明的全节点，而不仅是一台搜索 nonce 的设备。

## 能够自证的当前状态

每个 `HistoryStep` 证明当前区块关系，并在同一个关系中验证前一个终端。证明大小与验证工作量不会随区块高度增长。

活跃节点保存精确的活状态、用于累计工作量的紧凑区块头，以及供竞争矿工和链重组使用的最近 18 个完整区块。新加入节点用匹配的终端认证已最终确定的状态，再按常规方式验证近期后缀。

ParanO(1)d 消除的是对历史执行的依赖，并非不保存状态。状态传输量仍随活 UTXO 集增长；不再随链龄增长的，是证明“该状态为何有效”所需的执行量。

## 无签名所有权

地址是 256 位支出秘密经 Poseidon2b 映射后的结果。所有权通过零知识证明来表达：证明者知道该原像，并把证明绑定到完整逻辑交易。网络中不存在交易公钥，也不存在交易签名。

每次支出都会独立随机化授权胶囊，即使重复使用同一地址也是如此。交易共识不包含椭圆曲线。libp2p 使用的 Ed25519 密钥只标识对等节点，不具备支出权限或共识权力。

ParanO(1)d 是透明系统，并非隐私链。金额、所有者和转发中的交易都是公开的。零知识保护的是支出 witness；交易历史的隐私来自“不长期保留”，而不是隐藏交易内容。

## 可复用的活 UTXO 状态

状态是一个精确的、带索引的稀疏 UTXO 向量。支出会清空槽位，分配器优先复用空位，再扩展新的状态空间。每个输出都有新的 `creation_id`，因此复用索引绝不会让旧引用重新生效。

向量按每段 `2^16` 个槽位切分。空段是虚拟的；最后一个 UTXO 被花费后，整段便会消失。槽位域从 `2^24` 开始扩展，无需复制状态、迁移输出或暂停网络。

手续费区分普通 I/O 与净新增状态。状态增长部分随占用率上升并被销毁；归并不支付增长销毁费。每次扩展状态域时，区块奖励减半，但永久保留 1 NOID 的下限。

## 统一的二进制证明栈

协议构建在二进制塔域 `GF(2^128)` 上。Poseidon2b 是地址、交易、Merkle 树、状态根、transcript、区块标识和工作量证明共同使用的置换。

FROST-GKR 把批量 Poseidon2b 与 Merkle 路径压入共享布尔超立方体上的直接七次关系。批量 sumcheck、zerocheck、lincheck 与 FRI-Binius 在无需可信设置的前提下闭合二进制 R1CS 关系。钱包授权、精确状态转换和递归链验证因而能在同一算术系统中组合，而不是事后拼接多个互不相同的证明系统。

## 可量化的后量子安全下界

后量子安全被视为整个协议的属性，而不是从某一种签名方案或证明原语继承来的标签。协议分别核算所有安全关键组件，并以其中最弱的界作为组合结果：

| 组件 | 后量子安全强度 |
|---|---:|
| 钱包授权 | 79 位 |
| 递归 `HistoryStep` | 83 位 |
| Poseidon2b 抗碰撞强度 | 85 位 |
| Poseidon2b 抗原像强度 | 128 位 |
| **完整协议下界** | **79 位** |

最终结果是：**完整共识证明流水线具有经过证明的 79 位后量子工程安全下界**。计算被固定在可执行的
[可靠性账本](https://github.com/ignotusnemo/parano1d/blob/main/noid_gkr/src/zk_auth_qrom.rs)
中，因此协议改动无法悄然改变已经发布的数值。

## 协议概况

| 参数 | 数值 |
|---|---:|
| 平均目标出块时间 | 15 秒 |
| 默认矿工类别 | B64，`m=23`，最多 64 个用户页 |
| 大型矿工类别 | B255，`m=24`，最多 255 个用户页 |
| 每个区块的最大逻辑交易数 | 255 |
| 单页交易的最大吞吐量 | 17 TPS |
| 单笔交易的最大输入数 | 1,020 |
| 单笔交易的最大输出数 | 256 |
| 近期区块与重组后缀 | 18 个区块 |
| 状态域 | `2^24` 至 `2^32` 个槽位 |

- 阅读[架构概览](architecture/overview.md)，跟踪交易从钱包进入已接受状态的完整过程。

- [运行内置或外部矿工](mining/index.md)。
- 使用项目固定的 Rust toolchain 查看或构建[源代码](https://github.com/ignotusnemo/parano1d)。
