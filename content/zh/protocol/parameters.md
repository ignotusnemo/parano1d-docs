# 共识参数

本页汇总网络初始共识常量。除非另有说明，所有数值均为整数。

| 参数 | 数值 |
|---|---:|
| 目标出块间隔 | 15 秒 |
| ASERT 参考周期（reference epoch） | 6 个区块 |
| ASERT 半衰期（half-life） | 90 秒 |
| 过去时间中位数（median-time-past，MTP）窗口 | 11 个区块头 |
| 最大未来时间戳偏移 | 120 秒 |
| 交易周期（epoch） | 144 个区块 |
| 硬最终性深度 | 18 个区块 |
| 最大可接受重组 | 17 个区块 |

| 撤销数据保留 | 36 个区块 |
