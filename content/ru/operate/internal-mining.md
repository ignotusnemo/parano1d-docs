# Встроенный майнинг

Встроенный режим оставляет выбор транзакций, построение доказательства, поиск
nonce и отправку блока в одном процессе Core.

## Подготовка

Запустите проверку совместимости оборудования:

```sh
parano1d --check-hardware
```

Получите адрес выплаты из кошелька ноды:

```sh
parano1d
parano1d-cli address --list
parano1d-cli stop
```

Если отдельная выплата не задана, автоматически используется активный адрес
кошелька.

## Запуск

В текущем терминале:

```sh
parano1d --mode miner --cpu-threads 12
```

Либо обновите файл службы systemd:

```ini
ExecStart=/usr/local/bin/parano1d \
  --config /etc/parano1d/parano1d.toml \
  --mode miner \
  --cpu-threads 12
```

Затем перечитайте конфигурацию и перезапустите службу:

```sh
sudo systemctl daemon-reload
sudo systemctl restart parano1d
```

## Готовность

Для обычного майнинга нужны два аутентифицированных пира и синхронизированная
цепь. Проверьте:

```sh
parano1d-cli status
parano1d-cli peers
parano1d-cli mining
```

Процесс готовит встроенные матрицы доказательств B25 и B255 и выбирает лучшую
доступную реализацию для CPU. Производство блоков всегда начинается с B25; более
крупные шаблоны B255 используются только тогда, когда измеренное полное время
подготовки это позволяет.

## Распределение CPU

`--cpu-threads` задаёт общий бюджет потоков для доказательства и PoW. Значение
не должно превышать число логических CPU, доступных службе внутри cgroup или
виртуальной машины.

На инфраструктурной ноде оставьте ресурсы операционной системе и публичному
P2P-сервису. Выделенный майнер может использовать все доступные логические CPU.

Доказательство транзакции кошелька локально приоритетнее текущего майнинга. На
состав транзакций и блоков, принимаемых другими нодами, это не влияет.

## Смена выплаты

Активный адрес кошелька определяется для каждого нового шаблона. Его смена
делает локальную работу недействительной либо обновляет её на безопасной границе.
Неизменяемый готовый шаблон переписать уже нельзя.

Для постоянной отдельной выплаты процесса:

```sh
parano1d --mode miner --miner-address o1...
```

Используйте полный адрес bech32m.

## Остановка

Остановите ноду через RPC или менеджер служб:

```sh
parano1d-cli stop
```

```sh
sudo systemctl stop parano1d
```

Корректное завершение отменяет майнинг, закрывает сеть и сбрасывает MDBX на
диск. Не отправляйте повторные жёсткие сигналы только потому, что активному
доказательству требуется несколько секунд до безопасной границы отмены.
