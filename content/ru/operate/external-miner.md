# Внешний майнер

Внешний майнинг отделяет поиск PoW nonce от узла. Mempool, выбор транзакций,
переход состояния, доказательство `HistoryStep`, шаблон и ретрансляция блока
по-прежнему принадлежат узлу.

Worker не получает ни тело блока, ни witness доказательства.

## Локальный worker

Запустите узел в режиме внешнего майнера с bearer-токеном:

```sh
parano1d --mode extminer --mining-key 'LONG-RANDOM-TOKEN'
```

В другом терминале:

```sh
parano1d-miner \
  --rpc http://127.0.0.1:9401 \
  --key 'LONG-RANDOM-TOKEN'
```

Если узел запущен с `--mining-key`, токен обязателен даже через loopback.

При необходимости ограничьте число потоков:

```sh
parano1d-miner --key 'LONG-RANDOM-TOKEN' --threads 8
```

## Удалённый worker

Не выставляйте незашифрованный bearer-токен и общий RPC напрямую в интернет.

Разместите worker и узел в аутентифицированной приватной сети либо завершайте
TLS и ограничивайте доступный путь на обратном прокси. Публикуйте RPC только
после настройки защищённого транспорта:

```sh
parano1d \
  --mode extminer \
  --rpc-listen 0.0.0.0:9401 \
  --mining-key 'LONG-RANDOM-TOKEN'
```

Межсетевой экран должен пропускать порт только от нужных worker или прокси.

## Выплата

По умолчанию шаблоны используют адрес выплаты, настроенный на узле. Для
соло-майнинга это самый безопасный режим.

Чтобы разрешить worker запрашивать собственную выплату, оператор должен явно
включить эту возможность:

```sh
parano1d \
  --mode extminer \
  --mining-key 'LONG-RANDOM-TOKEN' \
  --allow-custom-coinbase
```

Тогда worker может передать:

```sh
parano1d-miner \
  --key 'LONG-RANDOM-TOKEN' \
  --coinbase o1...
```

Пользовательский coinbase меняет только выплату, зафиксированную до построения
доказательства. Сам доказанный шаблон worker изменить не может.

## Жизненный цикл шаблона

`getBlockTemplate` возвращает непрозрачный одноразовый ID, 16-полевое
расписание PoW, индекс nonce и target. Worker перебирает случайные независимые
диапазоны nonce и вызывает `submitBlock` ровно с 16 байтами nonce в
little-endian.

Шаблон живёт 30 секунд. Он также становится недействительным при смене
канонической вершины, успешной отправке или отмене узлом. Устаревший результат
нормален: после интервала опроса worker запрашивает новый шаблон.

## Диагностика

Выполните:

```sh
parano1d-miner --check-hardware
```

Если запросы не проходят:

- `401 Unauthorized` означает отсутствие или несовпадение токена;
- ошибка пользовательского coinbase означает, что узел его не разрешил;
- постоянное устаревание шаблонов обычно связано с новыми вершинами либо
  слишком долгим построением доказательства;
- отсутствие шаблона означает, что узел не синхронизирован, не имеет кворума
  пиров или запущен не в режиме `extminer`.
