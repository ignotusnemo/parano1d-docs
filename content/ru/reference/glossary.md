# Глоссарий

## Активный адрес

Владелец кошелька, который сейчас используется для отправок, сдачи и выплаты
встроенного майнера по умолчанию. Другие созданные адреса остаются
корректными, но их UTXO не смешиваются с расходованием активного владельца.

## Accepted block bundle

Атомарная пара канонических байтов блока и соответствующего terminal
`HistoryStep`.

## B64 / B255

Два стартовых класса доказательства `HistoryStep`. Они доказывают одно
отношение с разной эффективной вместимостью страниц.

## Block ID

Доменно разделённый хеш Poseidon2b полного канонического заголовка, включая
nonce. Используется для родительских ссылок и идентичности цепи.

## Хранение тела

Окно из 18 блоков, в котором обслуживаются полные данные транзакций.
Заголовки постоянны.

## Creation ID

Новый идентификатор, назначаемый при записи UTXO в слот. Он не позволяет
устаревшей ссылке потратить следующего владельца того же числового слота.

## FROST-GKR

Committed-column reduction, выражающий пакетные отношения Poseidon2b и Merkle
на общих булевых гиперкубах и сводящий их через multilinear sumcheck.

## Жёсткая финальность

Правило консенсуса, исключающее цепи-кандидаты, которые заменяют префикс глубже
последнего 18-блочного суффикса.

## History-stateless

Проверка не требует воспроизводить исторические транзакции. Узел всё равно
хранит и передаёт текущее живое состояние.

## HistoryStep

Рекурсивное отношение блока, доказывающее корректность текущего перехода,
точное состояние после него и предыдущий terminal.

## Логическая транзакция

Один атомарный `PagedSpend`, который может состоять из нескольких физических
страниц, но имеет один ID и одну авторизацию кошелька.

## Материализация

Запись уже доказанных изменений канонических слотов в точное локальное
состояние полного узла. Не следует путать с вычислением или доказательством
перехода.

## μNOID

Атомарная денежная единица. Один NOID равен 1 000 000 μNOID.

## PagedSpend

От одной до 128 упорядоченных страниц `Tx8x2`, объединённых в один атомарный
intent кошелька.

## Чек

Самодостаточное описание транзакции и восьмиуровневый путь Merkle,
доказывающий включение под заявленным корнем транзакций канонического
заголовка.

## Semantic header ID

Проекция заголовка без nonce, связанная внутри `HistoryStep`. Она фиксирует
все остальные консенсусно значимые поля заголовка.

## Слот

Одна индексированная позиция точного разреженного вектора UTXO.

## Снимок

Сегментированный перенос живого состояния на финализированной границе.
Manifest, корни сегментов, канонический заголовок и terminal проверяются до
установки.

## Сжигание за рост состояния

Часть комиссии за чистое увеличение числа живых слотов UTXO. Она зависит от
заполнения и не может быть получена майнером.

## Terminal

Результат рекурсивного доказательства фиксированной формы для текущего
`HistoryStep`.

## Tx8x2

Фиксированное физическое тело транзакции с восемью возможными входами и двумя
возможными выходами.
