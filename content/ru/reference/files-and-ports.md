# Файлы, порты и лимиты

## Стандартные пути

| Путь | Назначение | Полномочия |
|---|---|---|
| `~/.parano1d/parano1d.toml` | Конфигурация Core | Оператор |
| `~/.parano1d/gui-settings.json` | Настройки GUI | Локальный UI |
| `~/.parano1d/data/` | Стандартные данные узла Core и GUI | Состояние консенсуса |
| `DATA_DIR/wallet.key` | 256-битный мастер-секрет кошелька | Право расходования |
| `DATA_DIR/wallet.receipts` | Сохранённые исходящие чеки | Локальные платёжные свидетельства |
| `DATA_DIR/wallet.history` | Локальная история кошелька | Локальное представление |
| `DATA_DIR/p2p_identity.key` | Постоянная Ed25519-идентичность libp2p | Только сетевая идентичность |
| `DATA_DIR/peers.json` | Успешные публичные исходящие пиры | Подсказка обнаружения |
| `DATA_DIR/history-step-cache/` | Производный локальный кеш proof-матриц | Восстанавливается |
| `DATA_DIR/snapshot-staging/` | Временные данные входящего снимка | Никогда не канонические |
| `DATA_DIR/parano1d-gui.toml` | Конфигурация узла, управляемого GUI | Приватный узел |
| `DATA_DIR/parano1d-node.log` | Лог узла, управляемого GUI | Диагностика |

В Windows `~` означает каталог профиля пользователя.

На Unix файлы `wallet.key` и `p2p_identity.key` доступны только владельцу.
Первый управляет средствами, второй — нет.

## Порты

| Порт | Bind | Назначение | Публичный |
|---:|---|---|---|
| TCP 9400 | `0.0.0.0` | libp2p | Да |
| TCP 9401 | `127.0.0.1` | JSON-RPC | Нет |

Удалённый внешний майнинг может использовать RPC только через защищённый
приватный или TLS-транспорт. Bearer-токен аутентифицирует запросы, но не
шифрует их.

## Сетевая идентичность

| Параметр | Значение |
|---|---|
| Network magic | `NOID` |
| Протокол libp2p | `/noid/mainnet/1.0.0` |
| Gossip транзакций и блоков | GossipSub |
| Обнаружение | DNS-сиды, Kademlia, mDNS |

## Хранение

| Данные | Окно |
|---|---:|
| Заголовки | Постоянно |
| Полные принятые блоки | 18 |
| Реорганизуемый суффикс | 18 |
| Максимальная реорганизация | 17 |
| Undo-записи | 36 |
| Эпоха транзакций | 144 |

Чеки сохраняют доказательство конкретного платежа за пределами окна тел.
