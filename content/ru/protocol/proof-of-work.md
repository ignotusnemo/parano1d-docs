# Proof of work

Proof of work ParanO(1)d — доменно-разделённый digest Poseidon2b над
фиксированными полями семантического заголовка. Он выполняется после
доказательства `HistoryStep`, не зависящего от nonce.

## Расписание полей

Sponge `POWHDR__` поглощает ровно 16 элементов `GF(2^128)`:

| Индекс | Поле |
|---:|---|
| 0–1 | `prev_block_hash` |
| 2–3 | `state_root` |
| 4–5 | `tx_root` |
| 6 | `timestamp` |
| 7 | `height` |
| 8–9 | `miner_address` |
| 10 | 128-битный nonce |
| 11–12 | `difficulty_target` |
| 13 | `log_slots` |
| 14 | `active_slot_count` |
| 15 | `alloc_counter` |

32-байтные значения разделяются на две little-endian 128-битные половины.
Скалярные целые дополняются нулями. При rate, равном двум, расписание занимает
ровно восемь rate block и не требует padding переменной длины.

Домен PoW отличается и от nonce-bearing идентификатора блока, и от commitment
семантического заголовка без nonce.

## Сравнение с target

Digest и target интерпретируются как 256-битные little-endian целые. Nonce
валиден только при:

```text
pow_digest < difficulty_target
```

Равенство не проходит.

## ASERT

Целевой интервал блока — 15 секунд. ASERT использует опорную эпоху в шесть
блоков и half-life 90 секунд. На каждой высоте проверка выводит точный target из
канонического anchor, прошедшего времени и разницы высот.

Timestamp также обязан быть больше median time past предыдущих 11 заголовков и
опережать локальные часы проверяющей ноды не более чем на 120 секунд.

## Runtime kernels

Одна и та же фиксированная перестановка вычисляется пакетами nonce. Production
binary во время запуска выбирает лучшую поддерживаемую реализацию:

- базовую PCLMULQDQ на x86-64;
- AVX2 с VPCLMULQDQ при наличии;
- AVX-512 на поддерживаемых системах;
- NEON с PMULL на ARM64.

Пакетное исполнение меняет пропускную способность, но не digest. Скалярная
реализация служит тестовым oracle и не является production fallback.

## Граница внешнего майнинга

Внешний worker получает точное расписание из 16 полей, индекс nonce и target.
Он возвращает только канонический 16-байтный little-endian nonce. Перед
фиксацией блока нода проверяет его относительно неизменяемого одноразового
шаблона.

Worker не может изменить транзакцию, корень состояния, выплату или
доказательство. Решённый nonce для истёкшего либо устаревшего шаблона
отвергается.
