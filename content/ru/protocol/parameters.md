# Параметры консенсуса

На этой странице собраны стартовые константы консенсуса. Если не указано иное,
значения являются целыми.

## Время и финальность

| Параметр | Значение |
|---|---:|
| Целевой интервал блока | 15 секунд |
| Опорная эпоха ASERT | 6 блоков |
| Half-life ASERT | 90 секунд |
| Окно median time past | 11 заголовков |
| Максимальное опережение timestamp | 120 секунд |
| Эпоха транзакций | 144 блока |
| Глубина жёсткой финальности | 18 блоков |
| Максимальная допустимая реорганизация | 17 блоков |
| Хранение недавних полных блоков | 18 блоков |
| Хранение undo | 36 блоков |

| Параметр | Значение |
|---|---:|

## Классы доказательств

| Класс | Размерность | Эффективные позиции страниц |
|---|---:|---:|
| B64 | 23 | 0–64 |
| B255 | 24 | 65–255 |

Основная награда исключается из эффективного числа позиций. Активная
development-выплата занимает одну позицию.
