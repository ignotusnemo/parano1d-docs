# Настройки

Откройте настройки клавишей `F7`.

![Настройки кошелька](../assets/wallet/settings.png)

## Секрет

Вкладка «Секрет» показывает режим текущего мастер-секрета и предоставляет
явные операции обслуживания:

- экспорт текущего секрета из 64 шестнадцатеричных символов;
- импорт существующего секрета;
- замена секретом из пикселей фотографии;
- генерация нового секрета.

Замена полностью меняет производные адреса. Если текущий секрет управляет
средствами, которые нужно сохранить, сначала экспортируйте его.

Секрет — не обычная настройка приложения. Для этих операций кошелёк
останавливает приватный узел, атомарно обновляет защищённый файл ключа и заново
запускает состояние кошелька.

## Узел

Настройки узла управляют:

- каталогом данных;
- уровнем журналирования;
- перезапуском узла после изменения параметров, требующих перезапуска.

Терминальный просмотр журнала показывает ограниченный хвост настоящего лога
приватного узла. Текст можно выделить и скопировать для диагностики. Отдельное
постоянное хранилище логов для этого не создаётся.

Смена каталога данных переключает приложение на другую базу и другой
кошелёк. До применения внимательно проверьте путь.

## Сеть

Сетевые настройки задают:

- адрес прослушивания P2P;
- дополнительные адреса начальных узлов.

По умолчанию P2P слушает `0.0.0.0:9400`. Встроенное DNS-обнаружение работает
без пользовательских записей.

Не выставляйте приватный RPC как сетевой интерфейс. GUI и узел общаются
локально.
